# 💸 Pocket Bachao - Expense Tracker

A Flask web application to track daily expenses with interactive data visualization.

## ✨ Features
- **Real-time Budget Tracking**: ₹3000 default budget with live balance updates
- **Smart Alerts**: Dynamic status - "Chill kar bhai 😎" | "Sambhal ke bhai 😐" | "Khatam bhai 💸"  
- **Interactive Chart**: Doughnut chart using Chart.js for category-wise expense breakdown
- **CRUD Operations**: Add & view expenses with category, amount & notes
- **Dark Theme UI**: Clean, responsive interface

## 🛠️ Tech Stack
`Python` `Flask` `SQLite` `HTML5` `CSS3` `JavaScript` `Chart.js`
